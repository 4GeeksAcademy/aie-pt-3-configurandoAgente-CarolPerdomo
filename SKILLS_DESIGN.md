# Diseño de Skills de Nova

## Skill 1: Planificación y gestión de calendario

### 1. ¿Qué problema resuelve y cuándo debe activarse?
Esta skill ayuda a organizar actividades mediante Google Calendar cuando Carol solicita consultar, crear, modificar o eliminar eventos. Debe activarse cuando la solicitud implique una acción concreta sobre el calendario y exista suficiente información para realizarla.

### 2. ¿Qué herramientas utiliza y qué pasos debe seguir?
Utiliza las herramientas de Google Calendar disponibles mediante Zapier MCP.
Primero interpreta la intención y verifica los datos necesarios, como fecha, hora, duración y título. Después consulta el calendario cuando sea necesario para evitar conflictos y finalmente realiza la acción solicitada. Debe confirmar el resultado de la operación.

### 3. ¿Qué límites, confirmaciones y criterios de éxito debe respetar?
Nunca debe inventar datos faltantes. Debe preguntar antes de realizar acciones que puedan modificar o eliminar eventos si la intención o los datos no están claros. Se considera exitosa cuando la herramienta conectada confirma la operación y Nova comunica el resultado de forma clara.

## Skill 2: Creación y gestión de documentos

### 1. ¿Qué problema resuelve y cuándo debe activarse?
Esta skill permite convertir información proporcionada por Carol en documentos organizados mediante Google Docs. Debe activarse cuando Carol solicite crear, consultar, actualizar o modificar un documento.

### 2. ¿Qué herramientas utiliza y qué pasos debe seguir?
Utiliza las herramientas de Google Docs disponibles mediante Zapier MCP. Primero identifica el contenido y el objetivo del documento. Después utiliza la herramienta correspondiente para crear o modificar el documento y finalmente verifica que la operación haya sido realizada correctamente.

### 3. ¿Qué límites, confirmaciones y criterios de éxito debe respetar?
No debe inventar contenido que Carol no haya solicitado. Si la operación puede sobrescribir o modificar información existente y la intención no es inequívoca, debe preguntar antes de actuar. Se considera exitosa cuando Google Docs confirma la operación y Nova puede comunicar el resultado obtenido.
