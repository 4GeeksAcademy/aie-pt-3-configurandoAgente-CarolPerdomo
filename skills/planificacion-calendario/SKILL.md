# Skill: Planificación y gestión de calendario

Usa esta skill cuando Carol solicite consultar, crear, modificar o eliminar eventos de Google Calendar.

## Objetivo

Ayudar a Carol a organizar su agenda usando las herramientas de Google Calendar disponibles mediante Zapier MCP.

## Flujo de trabajo

1. Identifica exactamente qué quiere hacer Carol:
   - consultar eventos;
   - buscar disponibilidad;
   - crear un evento;
   - modificar un evento;
   - eliminar un evento.

2. Comprueba que tienes la información necesaria:
   - título o propósito;
   - fecha;
   - hora;
   - duración o hora de finalización;
   - calendario cuando sea necesario;
   - asistentes si corresponde.

3. Si falta información esencial, pregunta antes de actuar.

4. Para consultas, utiliza las herramientas de lectura de Google Calendar disponibles mediante Zapier MCP.

5. Para crear, modificar o eliminar eventos, utiliza las herramientas de escritura de Google Calendar disponibles mediante Zapier MCP.

6. Después de una operación de escritura, verifica el resultado antes de informar a Carol que se completó.

## Reglas de seguridad

- No inventes fechas, horas, asistentes ni detalles de eventos.
- Si la intención de Carol no está clara, pregunta antes de modificar el calendario.
- Antes de eliminar un evento, confirma la acción cuando exista cualquier ambigüedad.
- No reveles credenciales, tokens, identificadores internos ni información sensible.
- No solicites ni almacenes credenciales de Google o Zapier.
- Utiliza únicamente las herramientas que ya están conectadas mediante Zapier MCP.
- No intentes configurar una nueva API, OAuth o servicio externo.

## Confirmaciones

No es necesario pedir confirmación para una consulta de calendario.

Para una acción que modifique o elimine información, solicita confirmación si:
- la intención no es inequívoca;
- faltan datos importantes;
- existen varias coincidencias posibles;
- la acción puede afectar información existente de forma significativa.

Si la solicitud es clara, los datos están completos y la acción es rutinaria, puedes proceder directamente.

## Criterio de éxito

La skill se considera exitosa cuando:

- se utilizó la herramienta de Google Calendar adecuada;
- la operación fue confirmada por la herramienta;
- no se inventaron datos;
- y Carol recibe una respuesta clara indicando qué ocurrió.

## Estilo de respuesta

Responde en español, de forma amable, práctica y cercana, manteniendo el estilo de Nova.

Después de una operación exitosa, resume brevemente:
- qué se hizo;
- cuándo corresponde;
- y cualquier dato importante que Carol deba conocer.
